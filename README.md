# ✅ Smart Task Management & Productivity App (For Human-Computer Interaction course [282 CSE])

Tasky is a **task management and productivity** application designed to help users **organize tasks, set priorities, track progress, and improve study habits**. It includes a **calendar, study techniques, and task progress tracking** to enhance efficiency.

## 📌 Features
- **Task Management**: Create, edit, delete, search, and sort tasks.
- **Task Prioritization**: Assign priority levels (high, moderate, low).
- **Calendar Integration**: View tasks and events in a calendar format.
- **Study Techniques**: Utilize **Pomodoro** and **custom study timers**.
- **Task Progress Tracking**: View **weekly & monthly** task completion graphs.
- **Custom Notifications & Reminders**.
- **Dark Mode & Customizable UI**.

---

## 🚀 How to Run Tasky
1. Navigate to the `Release` folder.
2. Extract `Tasky.rar` using **WinRAR** or any archive tool.
3. Open the extracted folder and run **`Tasky.exe`**.
4. Start managing your tasks!
